MCOE Pulse (demo)
Open index.html in a browser. No install needed.
Roles: Student and Club member (choose at sign-up; a club member picks their club).
Data (accounts, events, registrations) is saved in your browser's localStorage, so this is a front-end demo:
passwords are not secure and data is not shared between devices. For a real launch, move the data to a backend (Supabase, Firebase or Node + database).
Club names come from the official MCOE site; descriptions, events and department tags are sample content. Add the official logo and photos yourself.
